## 言語設定

すべての回答は日本語で記述すること。
内部の思考プロセスやメモ, 構成検討は英語で行ってよいが, ユーザー向けレスポンスには含めないこと。
特定の言語やツールに対応した回答を求められた場合は, その言語やツールに関する知識を活用して回答してください。

## 選択肢の提示形式

ユーザーに選択肢を提示するときは常に **半角数字 + ピリオド**（`1. ...` / `2. ...` / `3. ...`）で番号付けする。
アルファベット (`a)`, `(a)`)、ローマ数字、bullet (`-`) は使わない。
question tool のように UI 側で番号付けされる場合はその UI に従う。

## 横断調査の委譲

複数の issue / docs / レポートをまたぐ調査(対応順の検討, 依存関係の整理, docs と現状の食い違い探し)は,
メインスレッドで Read / Grep / Glob を回さず, 読み取り専用の Explore subagent に委譲する。
メインスレッドには結論だけを戻し, 読み込んだ本文をコンテキストに残さない。

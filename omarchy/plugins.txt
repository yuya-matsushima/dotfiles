# Omarchy のシェルプラグイン (third-party) を宣言する。
# 形式: <plugin-id> <git-url> [placement]
#   - placement はバーウィジェットの初期位置 (left / center / right)。省略可。
#   - `#` 以降はコメント。空行は無視される。
#   - 既に導入済みなら有効化だけ行うため, 何度実行しても安全。
#   - placement は新規導入時と無効からの復帰時だけ適用し, 既存の位置は動かさない。
#
# 追加したら `make omarchy_plugins` (または `make omarchy`) を実行する。
# 導入元: https://plugins.omarchy.org/
